# Facial Recognition Class Project

## Project Overview
This project focuses on preprocessing image datasets and implementing basic facial detection and analysis using Python. Developed as part of coursework in data science and engineering, the project emphasizes image data wrangling, grayscale conversion, feature extraction, and evaluating detection performance.

## Objectives
* Preprocess and clean image datasets to prepare unstructured data for analysis.
* Implement face detection using computer vision techniques and `OpenCV`.
* Extract key facial features and evaluate system performance under varying conditions.
* Document findings in a clean technical summary.

## Tech Stack
* **Language:** Python
* **Libraries:** OpenCV (`cv2`), NumPy, Matplotlib
